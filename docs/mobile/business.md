# モバイルの業務ルール

金額・分類・相談判断の正本は [サーバー業務](../server/business.md)。この文書は利用者の操作と表示を扱う。

- B-M01: 保存・取込・相談が完了した表示は、サーバーの成功応答を受けてから出す。失敗時は理由と再試行可能な操作を示す。
- B-M02: CSVはプレビューと確定を区別する。プレビュー表示だけで登録済みと扱わない。重複件数などの確定結果を反映する。
- B-M03: 金額・残額・verdictはサーバーの結果を表示する。画面側に別の支出可否判定や独自カテゴリ判定を追加しない。
- B-M04: 相談、追加情報、実際の結果記録を区別する。助言の取得を支出実行として記録しない。
- B-M05: 未ログイン・期限切れ・ログアウト後は保護データを表示しない。ユーザー切替で以前のデータや処理結果を引き継がない。
- B-M06: 読込中・空・失敗・成功を区別する。操作による変更は関係する一覧・集計・メモリ表示へ反映する。

確認例: CSV確定失敗時に成功表示が出ない、ログアウト直前の通信が新ユーザーの画面へ反映されない、相談結果保存後に関連表示が更新される。
