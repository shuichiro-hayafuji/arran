# データの保存と外部AI送信の整理案

Issue #49・#132の検討用。2026-11-24時点のリポジトリの実装と公開資料を整理したもので、公開用の説明、保存期間、法的な判断を確定するものではない。本番環境の実設定・契約と異なる可能性があるため、この文書をそのまま同意画面の本文に設定しない。

## アプリで扱う情報

| 情報 | 実装上の保存・用途 | 保持・削除で未決の事項 |
| --- | --- | --- |
| 利用者・認証 | 利用者とパスワードハッシュ、セッションのハッシュと期限をDBに保存し、本人確認に使う。[認証](../../server/docs/authentication.md) | 退会、アカウントと関連情報の削除時期・手順を確定する |
| 相談・会話・記憶 | 相談文、回答、根拠、会話、関連する記憶や購入予定・実績などをDBに保存し、次の相談に使う。[相談の保存](../../server/docs/chat-consultation.md) | 保存期間と削除・訂正を確定する。「忘れて」は以後のモデル入力から対象を除くが、画面で見える履歴も削除するという意味ではない |
| CSVからの取引 | 日付・金額・カテゴリのほか、取り込んだ原明細や取込履歴・訂正履歴をDBに保存する。元のCSVファイル自体の復元・ダウンロードは提供していない。[取込管理](../../server/docs/csv-import-management.md) | 保存期間、取込履歴・原明細・監査記録の削除方法を確定する |
| 未確定CSVプレビュー | 所有者、全明細、確認情報と30分の期限をDBに保存する。期限切れでも、同じ利用者が次のプレビューを保存するまで残る場合がある。[保存と掃除](../../server/docs/csv-import-management.md) | 期限切れデータの定期削除と、利用を再開しない場合の保持期間を決める |
| AIへの送信同意 | 説明の版、本人ごとの同意・撤回状態と、結果不明の送信記録をDBに保存する。[DB契約](../../server/docs/database-schema.md) | 保持期間と、結果不明記録を安全に解消する方法を決める |
| 利用量・運用記録 | AI呼出しの利用者・操作・モデル・トークン数と発生時刻を記録する。利用量テーブルには相談文やモデル出力を保存しない。[DBスキーマ](../../server/docs/database-schema.md) | 運用ログ・利用量・監査情報の保持期間、アクセス権限、削除方法を確定する |
| バックアップ | 想定構成はDBのバックアップを外部へ保存し、S3の現行objectを7日で論理的に期限切れにする。非同期削除やversioningのため、厳密な物理削除期限を保証しない。[運用手順](../../infra/operations/README.md) | 実配備の設定、復旧点、退会・削除とバックアップの関係を確認する |

保存・削除に関する上記はコードと手順の確認であり、現在の本番DB、バックアップ、ログ設定の実態確認ではない。

## 外部AIへ送る情報

実装はOpenAI Responses APIへ `store:false` を指定する。現在のチャット相談では、相談メッセージ、直近の会話と回答の根拠・前提、関連する過去相談と記憶、購入予定・実績、日付・金額・カテゴリに限定した取引情報などを送る。旧相談・月次レビュー・結果からの記憶抽出にもそれぞれ送信経路がある。銀行CSVの原文・加盟店・口座名・明細本文は取引DTOに含めない。一方、自由文の秘密情報を完全に除去できる保証はない。項目と制約の詳細は[送信境界](../../server/docs/chat-consultation.md)と[OpenAI adapter](../../server/internal/infrastructure/openai/client.go)を参照する。

OpenAIの[データ管理の公式資料](https://developers.openai.com/api/docs/guides/your-data)は、Responses APIの不正利用監視ログについて通常30日間の保持と例外を説明している。[会話状態の資料](https://developers.openai.com/api/docs/guides/conversation-state)は、レスポンスを後から取得するための保存を `store:false` で無効にできると説明している。`store:false` だけで外部事業者によるあらゆる保存がゼロになるとは扱わない。契約・プロジェクト固有の設定や例外は未確認。

アプリの現行コードは `https://api.openai.com/v1/responses` を使う。処理国・地域や適用される契約条件を、このURLだけから確定しない。OpenAIの[再委託先一覧](https://platform.openai.com/subprocessors/)は変更され得るため、公開前に適用対象と最新内容を確認する。

## 公開前に決めること

1. データごとの保存期間、削除・退会時の扱い、バックアップや運用ログとの関係を決める。
2. 実際のOpenAIアカウントの契約、データ制御・処理地域と再委託先を確認し、第三者提供・委託などの整理を必要に応じ法務確認する。
3. 送信前に示す本文に、送信先、情報、目的、撤回方法、送信中の撤回と結果不明時の扱いを含める。本文と版は同時に審査し、実装・公開ポリシー・App Privacyと照合する。
4. 説明版のDB設定・サーバー設定、旧APIの停止、本人による同意・拒否・撤回・再同意を本番相当環境で検証する。結果不明記録を自動削除せず、安全な確認・復旧手順を整える。

現行実装の説明本文と有効版は初期状態では未設定であり、その間は同意付与と外部AI送信を拒否する。設定の実施は別の運用作業とし、この整理案の作成だけで実施しない。
