# FB-20261122-01: IPA作成テストで接続先の末尾の誤りを検出する

- 発生日・最終更新日: 2026-11-22
- 状態: 完了
- 対象領域: iOS IPA作成
- 仕様と出典: [Issue #131](https://github.com/shuichiro-hayafuji/arran/issues/131)、2026-11-22の[PR #133](https://github.com/shuichiro-hayafuji/arran/pull/133)のレビューで、接続先の部分一致が指摘された。

## 指摘と根拠

IPA作成時、Flutterには指定どおりの接続先が渡る必要がある。[テスト](../../../tools/test_ios_ipa.py)は全引数を連結した文字列の一部を照合していた。スクリプトのコピーで接続先に `/wrong` を付けても、修正前は5件すべて成功した。

## 原因と対応

模擬Flutterが記録した引数を行ごとに読み、両入口の既定URLと明示したURLを、それぞれ引数全体と照合する。書き出し方式は `--export-method` の次の引数と照合する。期待する接続先はIssueと[配布手順](../../../mobile/README.md)に明記されているため、テストの照合方法のみ修正した。
