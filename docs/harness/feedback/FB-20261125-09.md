# FB-20261125-09: 証跡 v2 の再読と移行テスト

- 対象: `evidence_intents` migration・退会証跡再読
- 関連: C-S03、C-S07
- 出典: 2026-11-25 Astra 独立レビュー
- 状態: 対応中

## 指摘と原因

v16 の権限試験で migration 23 が台帳に残ると、schema 履歴が連続せず migration に失敗する。完了と申込を別 SELECT で照合すると、それぞれ異なる snapshot を観測する可能性がある。不正時刻のテストでは既存 owner と operation の衝突が先に発生し、時刻検証を外しても拒否された。

## 対応と検証

v16 へ戻す際に 16 より大きい migration を台帳から除外する。完了と申込は同じ SELECT の self join で照合する。不正時刻のテストは未使用 owner と操作 ID を用い、行が残らないことも検証する。一般規則 C-S03/C-S07 は既存のため本文追加は不要。

専用 PostgreSQL で `check postgres-roles` と対象の `TestWithdrawalEvidenceV2Persistence` が成功。指摘の修正前失敗は再現していない。独立再レビュー待ち。v2 は本番未接続で、AWS・証跡の真正性・復元は未検証。
