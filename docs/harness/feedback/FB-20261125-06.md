# FB-20261125-06: AI 送信前記録と使用量確定の検証不足

- 発生日: 2026-11-25
- 最終更新日: 2026-11-25
- 状態: 対応中
- 対象領域: 外部 AI 送信、使用量記録
- 関連ルールID・正本リンク: B-S06、C-S07
- 出典: 同日の PR #140 独立レビュー

## 指摘と根拠

- 期待する結果: 送信前に同意と使用量の追跡行の両方が確実に保存され、使用量が欠損・不整合なら未確定にする。回答は会計の不確実性で失わない。
- 実際の結果・対象コード: [ai_consent.go](../../../server/internal/infrastructure/persistence/postgres/ai_consent.go)、[client.go](../../../server/internal/infrastructure/openai/client.go) は INSERT の 0 行と使用量の欠損を判別していなかった。
- 確認済みの事実・再現条件: 0 行の INSERT は SQL エラーにならず、Go の整数値は欠損・null を 0 と区別しない。
- 未確認事項: 実 runtime ロールと app.New を通した権限欠落・複数送信の一体検証。

## 原因と対応

- 原因・既存の対策で防げなかった理由: 書込み成功をエラーのみで判定し、会計情報を表示用と同じ型で読んでいた。構成と権限の一体検証も不足した。
- 実装の修正先: 追跡 2 行の RowsAffected を確認し、usage の必須値と整合性を検証する。usage 不正でも回答を保持する。
- 正本ルールの反映先、または追加不要の理由: C-S07 の既存の確実な結果確認と権限境界を適用し、重複追加しない。
- 回帰テスト・checker等の再発防止策: INSERT を trigger で 0 行にする分離 DB 回帰、および欠損・null・不正値・明示的な 0 と回答維持を確認する単体回帰を追加。
- 適用範囲・他領域への影響: 外部 AI 送信に限定。未確定の会計は退会処理を停止する。
