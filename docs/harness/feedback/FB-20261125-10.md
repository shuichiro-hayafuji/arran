# FB-20261125-10: 退会証跡 v2 の完了試行順序

- 対象: 退会証跡 v2 の試行固定
- 関連: C-S02、C-S07
- 出典: 2026-11-25 Astra 独立レビュー
- 状態: 対応中

## 指摘と原因

完了試行を申込と独立に固定すると、申込試行より前・同一世代や、不一致な隣接 hash に固定でき、整合する台帳を作れなくなる。固定は後から変更できないため自動再試行では回復できない。

## 対応と検証

同じ本人の申込行を DB 内でロックして有効な固定試行を読み、完了はより後の世代、隣接世代なら前 digest が申込 digest と一致する場合に限って固定する。既存固定の読戻しも同一 snapshot で順序を確認する。固定されていない申込、第1世代の完了、同一世代、不一致な前 digest を専用 PostgreSQL で拒否し、正しい固定と新規接続での再読を確認した。既存 C-S02/C-S07 の範囲のため本文追加は不要。

専用 PostgreSQL の `TestWithdrawalV2AttemptPersistence` は PASS。修正前の再現と独立再レビューは未実施。v2 は未接続で外部権威・lease・実 AWS は未検証。

追加再レビューで、同一世代のテストは申込が第1世代のとき非空 previous により別理由で拒否されることを指摘された。申込と同一の previous を使い、隣接世代は確実に異なる digest を設定するよう修正し、専用 PostgreSQL の対象回帰が PASS。独立再レビュー待ち。
