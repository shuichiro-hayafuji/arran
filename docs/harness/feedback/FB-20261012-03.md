# FB-20261012-03: 実モデルが購入意思未確定の予定を保存しなかった

- 発生日・最終更新日: 2026-10-12
- 状態: 完了
- 対象領域: チャット相談・モデル入力
- 関連ルール: [B-S01、B-S02、B-S03](../../server/business.md)、[確定要件](../../product/first-consultation-onboarding.md)
- 出典: 2026-10-12、PR #114の実モデル評価。合成の初回購入相談。

## 指摘と根拠

商品と金額を述べた相談は購入意思が未確定でも確認待ちとして保存する。a67f552の実モデルは購入候補を説明に利用したが、5ターンともpurchase_changeを返さず保存しなかった。制御したモデル応答のテストは成功しており、実抽出の品質を保証していなかった。

## 原因と対応

「明示的な購入予定」の範囲がプロンプトで不明確だった。[OpenAI Adapter](../../../server/internal/infrastructure/openai/chat.go)へ「買いたい」「迷っている」を予定として抽出する指示を追加。金融計算をGoへ移さず、予定保存だけでは残高・予算を減らさない境界を維持した。確定済み要件の解釈は変えていないため業務ルールの追加は不要。

再発防止として[実モデル評価](../../../server/docs/chat-consultation.md)に、初回の予定保存と残高未減額の照合を必須例として記録した。プロンプト文面を比較するだけのテストでは実抽出を保証できないため追加しない。既存の制御モデル回帰は保存・境界の検証として維持する。

## 検証と判定

| 実行日 | 検証 | 結果 | 根拠・限界 |
| --- | --- | --- | --- |
| 2026-10-12 | 修正前の合成ケース5件 | FAIL | 予定保存なし。実モデルgpt-5-mini / medium |
| 2026-10-12 | 修正後の同じ代表ケース5件 | PASS | 初回予定保存、訂正、厳しさ、再起動、忘却。Sendと保存後読取JSONが一致 |
| 2026-10-12 | serverハーネス | PASS | プロンプト変更後の境界・整形・vet・server/Agent全テスト |

代表ケースの抽出漏れは解消した。専用PostgreSQLで認証付きHTTPの初回相談も追加検証し、実モデルPOST/GET一致と未認証・失効後の拒否はPASS。確率的出力全般、実機、全代表ケースのHTTP E2Eは未確認であり、今回の修正完了と製品品質の最終承認を区別する。
