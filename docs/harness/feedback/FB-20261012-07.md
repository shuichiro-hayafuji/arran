# FB-20261012-07: OpenAPIの別契約への購入項目混入

- 発生日・最終更新日: 2026-10-12
- 状態: 完了
- 対象領域: OpenAPI、契約文書検証
- 関連ルール・正本: [OpenAPI](../../../server/docs/openapi.yaml)、[tool Index](../../../tools/INDEX.md)
- 出典: 2026-10-12の独立レビュー。base 0d54f93にも存在するYAML構文不正。

## 指摘と根拠

CSVプレビューのmultipart properties内のsource直後に、購入イベント用のbalance_applied_amount/free_budget_applied_amount/balance_basisが誤った階層で混入した。source_account_nameのインデントとの不整合でRuby標準YAML parserが173行をFAILとした。ローカルリンク検査のdocs check成功はYAML構文成功を保証しなかった。

## 原因と対応

同名sourceを持つ別契約へ購入項目を追加したことが原因。誤混入の3行だけを削除し、CSV propertiesのsource_account_nameとPurchase.events内の正しい3項目を保持した。既存標準parserによる検証を追加実行し、新依存やformatter変更は行わない。
